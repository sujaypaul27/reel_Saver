# Inst/Tube Saver 📥🎬

A fast, clean, and modern Android app to download **Instagram Reels** and **YouTube Videos** directly to your phone gallery in high quality.

---

## 📱 How to Install on Your Phone (Super Easy)

You do **not** need a computer to install this app. You can download and install it directly from your phone's web browser in 1 minute:

### Step 1: Download the App
1. Open this link on your Android phone (in Chrome or any browser):  
   👉 **[Download Latest APK](https://github.com/sujaypaul27/reel_Saver/releases)**
2. Under the latest version, tap on **`app-release.apk`** to download it.

### Step 2: Install the APK
1. When the download finishes, tap on the notification or open your phone's **Downloads** folder.
2. Tap **`app-release.apk`**.
3. If your phone shows a popup saying *"For your security, your phone is not allowed to install unknown apps from this source"*:
   - Tap **Settings** on the popup.
   - Turn **ON** the switch for **"Allow from this source"**.
   - Press the back button.
4. Tap **Install**.

### Step 3: Open and Grant Storage Permission
1. Open **Inst/Tube Saver**.
2. When the app asks for storage access, tap **Allow** so the app can save videos directly to your device storage and gallery.

## 🚀 How It Works (3 Easy Ways to Download)

### Method 1: Automatic Detection (Fastest) ⚡
1. Open **Instagram** or **YouTube**.
2. Find the Reel or Video you like and tap **Copy link**.
3. Open **Inst/Tube Saver** — the app immediately detects your copied link!
4. Choose your preferred video quality (e.g. 1080p, 720p, or Audio) and tap **Download**.

### Method 2: Share Directly from Instagram or YouTube 🔗
1. While watching any Reel or Video, tap the **Share** button.
2. Select **Inst/Tube Saver** from the list of apps.
3. The video will be added to your download queue. Pick your format and download!

### Method 3: Paste Manually 📋
1. Copy any video link.
2. Open **Inst/Tube Saver**.
3. Paste the link in the input box on the Home screen and tap **Search / Fetch**.
4. Select the format and start downloading.

## ✨ Features

* **High Quality Video & Audio**: Supports 1080p, 720p, 480p, 360p, and MP3 audio extraction.
* **Batch Downloads & Queue**: Download multiple videos at once with live progress percentage and download speed.
* **Persistent Queue**: Never lose pending downloads even if the app closes or your phone restarts.
* **Built-in History**: Watch downloaded videos with your favorite player or delete unwanted files to save space.
* **Storage Manager**: Easily view storage usage and clear temporary cache from Settings.
* **Beautiful Themes**: Switch between **Midnight Dark** (default deep navy with electric violet), **Classic Light**, and **Sunset Warm**.
* **5 Languages Supported**: English, हिंदी (Hindi), தமிழ் (Tamil), Español (Spanish), and Français (French).

## 🛠️ For Developers (Build from Source)

If you want to run or build the app from source code:

### Prerequisites
* [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.13+ or latest stable)
* Android SDK (API 34+)
* Java 17+

### Steps
```bash
# 1. Clone this repository
git clone https://github.com/sujaypaul27/reel_Saver.git

# 2. Go into the project directory
cd reel_Saver

# 3. Get dependencies
flutter pub get

# 4. Run tests
flutter test

# 5. Build release APK
flutter build apk --release
```

The compiled APK will be created at:
`build/app/outputs/flutter-apk/app-release.apk`
